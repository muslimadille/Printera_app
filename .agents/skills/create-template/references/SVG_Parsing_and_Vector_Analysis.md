# SVG Vector Analysis & Dieline Parsing Reference Guide

This reference guide provides comprehensive technical instructions for agents on how to parse, extract, normalize, and analyze SVG dieline files for packaging CAD templates.

---

## 1. SVG Unit System & Coordinate Space Normalization

SVG vector files generated by Illustrator, ArtiosCAD, CorelDRAW, or AutoCAD use various physical or display units.

### Conversion Factors to Millimeters (`mm`)
$$\text{Scale Factor to mm} = \frac{1}{\text{Units Per mm}}$$

| Original Unit | Abbreviation | Points per Unit | Scale Factor to `mm` |
| :--- | :--- | :--- | :--- |
| Millimeter | `mm` | $2.83464566929\text{ pt}$ | $1.0$ |
| Point | `pt` | $1.0\text{ pt}$ | $1 / 2.83464566929 \approx 0.3527777778$ |
| Pixel (96 DPI) | `px` | $0.75\text{ pt}$ | $25.4 / 96 \approx 0.2645833333$ |
| Inch | `in` | $72.0\text{ pt}$ | $25.4$ |
| Centimeter | `cm` | $28.3464566929\text{ pt}$ | $10.0$ |

### ViewBox & Unit Inspection Algorithm
1. Read root `<svg width="..." height="..." viewBox="...">`.
2. If `viewBox="0 0 885.58 706.29"` and physical width is `311.7mm`:
   $$\text{Scale Factor} = \frac{311.7}{885.58} = 0.3527777 \approx \frac{1}{2.83464566929}$$
3. All extracted coordinates $(X_{\text{raw}}, Y_{\text{raw}})$ MUST be multiplied by $\text{Scale Factor}$ to convert into millimeter user space.

## 2. Path Command Decoding (`M`, `L`, `C`, `H`, `V`, `A`, `Z`)

Complex packaging shapes (e.g. curved tuck tongues, lock tabs, slot cutouts) are stored inside SVG `<path d="...">` elements.

### Path Command Breakdown
- **`M x y` (Absolute Move)**: Starts a new sub-path at $(x, y)$.
- **`L x y` (Absolute Line)**: Draws a straight line to $(x, y)$.
- **`H x` (Horizontal Line)**: Draws a horizontal line to $(x, Y_{\text{current}})$.
- **`V y` (Vertical Line)**: Draws a vertical line to $(X_{\text{current}}, y)$.
- **`C x1 y1, x2 y2, x y` (Cubic Bezier)**: Draws a cubic Bezier curve with control points $(x1, y1)$ and $(x2, y2)$ ending at $(x, y)$.
- **`S x2 y2, x y` (Smooth Cubic Bezier)**: Draws a smooth cubic Bezier curve.
- **`A rx ry x-axis-rotation large-arc-flag sweep-flag x y` (Elliptical Arc)**: Draws an arc to $(x,y)$.
- **`Z` (Close Path)**: Closes path by drawing line to sub-path start.

## 3. Matrix Transform Flattening & Normalization

When an SVG element has a `transform` attribute (e.g. `transform="translate(-6.5 -6.501)"` or `transform="matrix(a,b,c,d,e,f)"`):
You MUST apply the transformation matrix directly to the coordinates before storing them:
$$\begin{bmatrix} X' \\ Y' \\ 1 \end{bmatrix} = \begin{bmatrix} a & c & e \\ b & d & f \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} X \\ Y \\ 1 \end{bmatrix}$$
For simple translation `translate(tx, ty)`:
$$X' = X + tx, \quad Y' = Y + ty$$

## 5. Automated Python Extraction Script

Agents can run this script to parse any reference SVG file:

```python
import xml.etree.ElementTree as ET

PT_PER_MM = 2.83464566929
def to_mm(pt): return round(pt / PT_PER_MM, 4)

def parse_svg_dieline(svg_path):
    tree = ET.parse(svg_path)
    root = tree.getroot()
    segments = []
    
    for idx, elem in enumerate(root):
        tag = elem.tag.replace('{http://www.w3.org/2000/svg}', '')
        cls = elem.attrib.get('class', '')
        stroke = elem.attrib.get('stroke', '')
        
        if tag == 'line':
            x1, y1 = to_mm(float(elem.attrib['x1'])), to_mm(float(elem.attrib['y1']))
            x2, y2 = to_mm(float(elem.attrib['x2'])), to_mm(float(elem.attrib['y2']))
            segments.append({'type': 'line', 'class': cls, 'start': (x1, y1), 'end': (x2, y2)})
        elif tag == 'polyline':
            pts_raw = elem.attrib['points'].split()
            pts = [(to_mm(float(pts_raw[i])), to_mm(float(pts_raw[i+1]))) for i in range(0, len(pts_raw), 2)]
            segments.append({'type': 'polyline', 'class': cls, 'points': pts})
            
    return segments
```
